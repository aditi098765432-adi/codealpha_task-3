# FitFlow — Fitness Tracker

A responsive fitness tracker built with **HTML, CSS and JavaScript**.

## Files
- `index.html` — app structure
- `style.css` — design and responsive layout
- `script.js` — tracker logic and local data saving

## Features
- Daily steps and active minutes
- Water intake tracker
- Workout/activity log
- Healthy habits checklist
- Progress bars and daily goal ring
- Saves data in the browser with localStorage
- Starts a fresh daily dashboard on a new date

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload all three files (`index.html`, `style.css`, `script.js`) to the root of your GitHub repository.
3. Commit the changes.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Open the published GitHub Pages link.

No backend or installation is required. The app stores data locally in the browser on the device being used.

**Note:** This project uses JavaScript (not Java).
